One word that describes my Wi-Fi, aiming to be both the funniest and the most
accurate: **Leashed** — the signal only works within a few steps of the router.

Entry for the [One Word for Your Wi-Fi](https://make.fun/c/u-tuan-muda-one-word-for-your-wi-fi-a1b4fd72)
competition on make.fun. The program writes the word to `/output/entry.txt`.
